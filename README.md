# 🛡️ Aegis Journal – Secure Personal Gemini Journal | APAC Edition

Zero-knowledge encrypted AI journaling companion powered by Google Gemini.

🎥 **Demo:** https://youtu.be/GoHMML2_tmE  
💼 **LinkedIn:** https://lnkd.in/p/d-YATird

> **Note:** Live deployment requires Firebase & Gemini API credentials. The project runs locally after adding the required environment variables.

## ✨ Features

- 🔒 Firebase Authentication
- 🛡️ Client-side AES-GCM encryption
- 🔑 PBKDF2 key derivation
- 🤖 Gemini AI mood analysis & insights
- 📝 Encrypted Firestore storage
- ⚡ React + Vite + Tailwind CSS
- ☁️ Cloud Run ready

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- Node.js + Express
- Firebase Auth
- Firestore
- Google Gemini API

## 🚀 Run Locally

```bash
git clone https://github.com/HemantSharma1803/aegis-journal-apac-edition
cd aegis-journal-apac-edition
npm install
npm run dev
```

Run backend:

```bash
node server.ts
```

or

```bash
bun run server.ts
```

## 📂 Important Files

- `server.ts` – Express backend
- `firestore.rules` – Firestore security rules
- `firebase-blueprint.json` – Firebase configuration
